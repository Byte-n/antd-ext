## 概述

TagsInput 组件的数字类型支持是一个专门针对数值输入场景的功能模块，它通过 `type='numeric'` 属性启用严格的数字校验机制。该功能基于 JavaScript 的 `Number.isNaN` 方法进行严格判断，确保用户只能输入有效的数字值，并提供了完善的错误提示和自动清除机制。

### 主要特性

- **严格数字校验**：使用 `Number.isNaN` 进行精确的数字验证
- **实时错误提示**：通过 Tooltip 组件提供即时反馈
- **自动清除机制**：3秒后自动隐藏错误提示
- **国际化支持**：多语言错误消息文本
- **受控模式支持**：完整的状态管理模式
- **批量处理**：支持批量数字输入和粘贴操作

## 数字校验机制

### 核心校验算法

数字类型支持的核心在于使用 `Number.isNaN` 方法进行严格判断。该方法与传统的 `isNaN()` 函数不同，它不会尝试将输入转换为数字后再判断，而是直接检查值是否为 NaN。

```mermaid
flowchart TD
Start([输入开始]) --> TrimInput["去除前后空白字符"]
TrimInput --> CheckEmpty{"输入是否为空?"}
CheckEmpty --> |是| ReturnFalse["返回 false"]
CheckEmpty --> |否| TypeCheck{"检查输入类型"}
TypeCheck --> |numeric| ConvertNumber["Number(input) 转换"]
TypeCheck --> |text| DirectUse["直接使用字符串"]
ConvertNumber --> IsNaNCheck{"Number.isNaN(numValue)?"}
IsNaNCheck --> |是| SetTooltip["设置错误提示"]
IsNaNCheck --> |否| CreateTag["创建数字标签"]
SetTooltip --> ReturnFalse
CreateTag --> AddToTags["添加到标签列表"]
DirectUse --> AddToTags
AddToTags --> ReturnTrue["返回 true"]
ReturnFalse --> End([结束])
ReturnTrue --> End
```

**图表来源**
- [src/TagsInput/index.tsx](file://src/TagsInput/index.tsx#L124-L161)

### 校验实现细节

在 `addTag` 方法中，数字校验的具体实现如下：

1. **输入预处理**：首先对输入字符串进行 `trim()` 处理，去除首尾空白字符
2. **空值检查**：如果输入为空字符串，直接返回 `false`
3. **类型判断**：根据 `type` 属性判断是否为数字类型
4. **严格转换**：使用 `Number()` 进行转换，然后通过 `Number.isNaN()` 进行严格判断
5. **错误处理**：如果转换失败，设置相应的错误提示信息

## 自动清除逻辑

### 3秒延迟清除机制

为了提供更好的用户体验，错误提示会在显示3秒后自动清除。这个机制通过 React 的 `useEffect` 和 `setTimeout` 实现：

```mermaid
flowchart TD
SetTooltip["设置错误提示"] --> CheckTitle{"inputTooltipTitle 是否有值?"}
CheckTitle --> |否| NoAction["无操作"]
CheckTitle --> |是| StartTimer["启动3秒定时器"]
StartTimer --> Wait3Seconds["等待3秒"]
Wait3Seconds --> ClearTooltip["清除提示内容"]
ClearTooltip --> CleanupTimer["清理定时器"]
CleanupTimer --> End["结束"]
NoAction --> End
```

2. **定时器管理**：使用 `setTimeout` 设置3秒延迟
3. **清理机制**：在组件卸载或新提示出现时清理旧定时器
