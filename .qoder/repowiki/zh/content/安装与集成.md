## 简介

antd-ext 是一个基于 dumi 构建的 React 组件库，专门对 Ant Design 进行增强与补充。它兼容 React 16 ~ 19，遵循 Ant Design 设计规范，支持国际化与主题定制，旨在提升开发效率与体验。

该组件库提供了丰富的增强组件和实用工具，包括：
- 增强现有 antd 组件（如 Table 自动高度、斑马纹等）
- 补充常用业务组件（如逻辑条件构建器、带确认的按钮等）
- 完整 TypeScript 类型定义与友好的 API 设计
- 与 antd 主题系统与国际化体系无缝协同

## 组件导入方式

### 全局导入

最简单的导入方式是直接从包中导入所需组件：

```typescript
import { LoadingIndicatorCircusBall, TagsInput, Sheet } from '@byte.n/antd-ext';

const MyComponent = () => (
  <div>
    <LoadingIndicatorCircusBall />
    <TagsInput />
    <Sheet />
  </div>
);
```

### 按需导入

为了优化打包体积，推荐使用按需导入的方式：

```typescript
// 单独导入特定组件
import LoadingIndicatorCircusBall from '@byte.n/antd-ext/LoadingIndicatorCircusBall';
import TagsInput from '@byte.n/antd-ext/TagsInput';
import Sheet from '@byte.n/antd-ext/Sheet';

// 或者使用解构导入
import { LoadingIndicatorCircusBall, TagsInput, Sheet } from '@byte.n/antd-ext';
```

### 导入类型定义

对于 TypeScript 项目，建议同时导入类型定义：

```typescript
import { 
  LoadingIndicatorCircusBall,
  LoadingIndicatorCircusBallProps,

  TagsInputProps,
  Sheet,
  SheetProps
} from '@byte.n/antd-ext';
```

## ConfigProvider 集成

### 基础配置

antd-ext 组件完全兼容 Ant Design 的 ConfigProvider，可以无缝集成到现有的 ConfigProvider 配置中：

```typescript
import { ConfigProvider, App } from 'antd';
import { LoadingIndicatorCircusBall, TagsInput } from '@byte.n/antd-ext';

const MyApp = () => (
  <ConfigProvider
    theme={{
      token: {
        colorPrimary: '#52c41a',
      },
    }}
    locale={zhCN}
  >
    <App>
      <MyApplication />
    </App>
  </ConfigProvider>
);
```

### 组件级配置

某些组件支持额外的 ConfigProvider 配置选项：

```typescript
import { ConfigProvider, App } from 'antd';
import { TagsInput } from '@byte.n/antd-ext';

const MyApp = () => (
  <ConfigProvider
    theme={{
      components: {
        TagsInput: {
          tagMaxWidth: 150,
          paddingSM: 8,
          controlHeightMD: 40,
        },
      },
    }}
  >
    <App>
      <TagsInput placeholder="请输入标签" />
    </App>
  </ConfigProvider>
);
```

### 主题 Token 配置

TagsInput 组件支持以下主题 Token 配置：

| Token | 说明 | 类型 | 默认值 |
|-------|------|------|--------|
| `tagMaxWidth` | 标签最大宽度 | `number` | `100` |
| `paddingSM` | 小尺寸内边距 | `number` | `4` |
| `paddingMD` | 中等尺寸内边距 | `number` | `6` |
| `paddingLG` | 大尺寸内边距 | `number` | `8` |
| `marginSM` | 小尺寸外边距 | `number` | `4` |
| `marginMD` | 中等尺寸外边距 | `number` | `6` |
| `marginLG` | 大尺寸外边距 | `number` | `8` |
| `controlHeightSM` | 小尺寸高度 | `number` | `24` |
| `controlHeightMD` | 中等尺寸高度 | `number` | `32` |
| `controlHeightLG` | 大尺寸高度 | `number` | `40` |
| `fontSizeSM` | 小尺寸字体大小 | `number` | `12` |
| `fontSizeMD` | 中等尺寸字体大小 | `number` | `14` |
| `fontSizeLG` | 大尺寸字体大小 | `number` | `16` |

## 主题与国际化配置

### 国际化配置

antd-ext 支持与 Ant Design 完全一致的国际化配置：

```typescript
import { ConfigProvider, App } from 'antd';
import zhCN from 'antd/locale/zh_CN';
import enUS from 'antd/locale/en_US';
import { TagsInput } from '@byte.n/antd-ext';

const AppWithLocalization = () => {
  const [locale, setLocale] = useState<'zh' | 'en'>('zh');

  return (
    <ConfigProvider
      locale={locale === 'zh' ? zhCN : enUS}
      theme={{
        token: {
          colorPrimary: '#1890ff',
        },
      }}
    >
      <App>
        <button onClick={() => setLocale(locale === 'zh' ? 'en' : 'zh')}>
          {locale === 'zh' ? 'Switch to English' : '切换到中文'}
        </button>
        
        <TagsInput placeholder="请输入标签" />
      </App>
    </ConfigProvider>
  );
};
```

### 主题定制

通过 ConfigProvider 的 theme 配置，可以轻松定制组件主题：

```typescript
import { ConfigProvider, App } from 'antd';
import { TagsInput } from '@byte.n/antd-ext';

const MyApp = () => (
  <ConfigProvider
    theme={{
      token: {
        // 全局主题 token
        colorPrimary: '#52c41a',
        borderRadius: 6,
        fontFamily: 'Arial, sans-serif',
      },
      components: {
        // 组件级别主题 token
        TagsInput: {
          tagMaxWidth: 120,
          controlHeightMD: 36,
          paddingMD: 8,
        },
      },
    }}
  >
    <App>
      <TagsInput placeholder="自定义主题的标签输入" />
    </App>
  </ConfigProvider>
);
```

## 常见集成问题与解决方案

### 样式未生效问题

#### 问题描述
安装后组件样式不显示或显示异常

#### 解决方案

1. **检查 antd 版本兼容性**
   ```bash
   # 确保 antd 版本 >= 6.0.0
   pnpm list antd
   ```

2. **验证 CSS 文件加载**
   ```typescript
   import '@byte.n/antd-ext/dist/index.css';
   ```

3. **检查样式优先级**
   如果与其他样式冲突，可以尝试提高样式优先级：
   ```css
   /* 在全局样式中提高优先级 */
   .ant-tags-input {
     all: unset;
   }
   ```

### 类型定义冲突

#### 问题描述
TypeScript 项目中出现类型定义冲突或找不到类型

#### 解决方案

1. **检查 TypeScript 配置**
   确保 `tsconfig.json` 中包含正确的类型路径：
   ```json
   {
     "compilerOptions": {
       "typeRoots": ["./node_modules/@types", "./node_modules/@byte.n/antd-ext"]
     }
   }
   ```

2. **手动导入类型声明**
   ```typescript
   /// <reference types="@byte.n/antd-ext" />
   ```

3. **检查模块声明**
   如果仍然有问题，可以参考项目中的模块声明文件：
   **节来源**
   - [src/typings.d.ts](file://src/typings.d.ts#L1-L33)

### 组件渲染问题

#### 问题描述
组件无法正常渲染或出现运行时错误

#### 解决方案

1. **检查 React 版本兼容性**
   ```bash
   # 确保 React 版本 >= 18.0.0
   pnpm list react
   ```

2. **验证组件导入方式**
   确保使用正确的导入语法：
   ```typescript
   // 正确
   import { TagsInput } from '@byte.n/antd-ext';
   
   // 错误
   import TagsInput from '@byte.n/antd-ext';
   ```

3. **检查依赖完整性**
   ```bash
   # 清理并重新安装依赖
   rm -rf node_modules pnpm-lock.yaml
   pnpm install
   ```

### 国际化配置问题

#### 问题描述
国际化设置不生效或语言包加载失败

#### 解决方案

1. **确保正确导入语言包**
   ```typescript
   import zhCN from 'antd/locale/zh_CN';
   import enUS from 'antd/locale/en_US';
   ```

2. **检查 ConfigProvider 配置**
   ```typescript
   <ConfigProvider locale={zhCN}>
     {/* 组件 */}
   </ConfigProvider>
   ```

3. **验证语言包完整性**
   检查语言包中是否包含 TagsInput 的本地化配置：
   **节来源**
   - [src/TagsInput/locale/index.ts](file://src/TagsInput/locale/index.ts)

### 性能优化问题

#### 问题描述
组件加载缓慢或内存占用过高

#### 解决方案

1. **使用按需导入**
   ```typescript
   // 使用 babel-plugin-import 或类似工具
   import { TagsInput } from '@byte.n/antd-ext';
   ```

2. **优化主题配置**
   只配置必要的主题 token，避免过度定制：
   ```typescript
   theme={{
     components: {
       // 只配置需要的组件 token
       TagsInput: {
         controlHeightMD: 32,
       },
     },
   }}
   ```

3. **懒加载组件**
   对于非关键路径的组件，可以考虑懒加载：
   ```typescript
   const LazyTagsInput = lazy(() => import('@byte.n/antd-ext/TagsInput'));
   ```

## 最佳实践

### 项目结构组织

建议将 antd-ext 组件的配置和使用集中管理：

```typescript
// components/ui/index.ts
export { default as LoadingIndicatorCircusBall } from '@byte.n/antd-ext/LoadingIndicatorCircusBall';
export { default as TagsInput } from '@byte.n/antd-ext/TagsInput';
export { default as Sheet } from '@byte.n/antd-ext/Sheet';

// providers/ThemeProvider.tsx
import { ConfigProvider, App } from 'antd';
import { theme } from './theme';

export const ThemeProvider = ({ children }: { children: React.ReactNode }) => (
  <ConfigProvider theme={theme}>
    <App>{children}</App>
  </ConfigProvider>
);
```

### 类型安全

充分利用 TypeScript 类型系统：

```typescript
import { TagsInputProps, TagsInput } from '@byte.n/antd-ext';

const MyTagsInput: React.FC<TagsInputProps> = (props) => {
  const handleChange: TagsInputProps['onChange'] = (value) => {
    console.log('Tags changed:', value);
    props.onChange?.(value);
  };

  return <TagsInput {...props} onChange={handleChange} />;
};
```

### 样式隔离

为了避免样式污染，建议：

1. 使用 CSS Modules 或 styled-components
2. 避免全局样式覆盖
3. 合理使用 ConfigProvider 的作用域配置
